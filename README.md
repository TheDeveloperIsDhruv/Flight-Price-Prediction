# ✈️ Flight Price Prediction Model

Predict flight ticket prices with ease using machine learning and a sleek web interface.

## ⚙️ Tech Stack
- **Flask** for backend  
- **HTML, CSS, Bootstrap** for frontend  
- **Python (scikit-learn, pandas, numpy)** for model  

## 🚀 Features
- User-friendly UI for flight details input  
- Instant fare prediction  
- Responsive and modern Bootstrap design
